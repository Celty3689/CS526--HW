Problem 2
The problem requires me to find all unique substrings of a string and count them using recursion. The idea of recursion is to break down a large problem into smaller ones and call itself. At first, I considered how to design the recursive function. The recursive function needs two parameters: the starting position i and the ending position j. The idea is to fix i and let j start from i + 1 and keep moving right to generate all substrings starting with i. When j reaches the end, i moves one position to the right and starts again. For de-duplication, I thought it would be most convenient to use Python's set directly because it automatically handles duplicate elements. I just need to add each generated substring to it. When writing the code, I first defined the main function, which contains a set to store the results, and then wrote the recursive function. After the recursion ends, I print all the substrings in the set separated by commas and then print the size of the set, which is the number of unique substrings. When testing with "abcab", it indeed output 12 unique substrings, proving that the idea was correct. 

Problem 3
When writing these three recursive reversals, my thought process was the same: first, recursively reach the last element, and then process each element from the end to the beginning.
For the array stack, recursively remove the top element of the stack. After the remaining part is reversed, insert the removed element at the bottom.
For the linked list, recursively reach the last node, and then adjust the pointer direction of each node one by one, making each node point to its previous node.
For the doubly linked list, the idea is the same as for the singly linked list, but an additional prev pointer needs to be handled.
The key point to confirm is this: recursion will first dive to the deepest level, and then start building from the last element in reverse order. This naturally achieves the reversal. There is no need for a loop; recursion can complete the entire reversal process on its own.
